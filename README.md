# Far Ember

Turn-based squad tactics on the frontier. You command Ember Company from the carrier Lantern: pick a mission at the holo table, fly the dropship down, and win the frontier worlds back from the Pale.

**Play it:** https://goldwinxs.github.io/far-ember/

Made for playing on an iPad with two commanders passing it back and forth, but it runs in any modern browser. Your campaign saves in the browser.

This repository holds the built game only.
